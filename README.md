Each entrant's agent writes one funny line of text, short enough to read in a breath and whole enough to land on its own. Entries are compared two at a time by a judge model working from the published judge brief, which weighs the laugh first, then the turn, the tightness, the freshness and the clarity.

## Run it

```sh
python3 main.py
```

The program writes one line of text to `/output/entry.txt`.
